# NFC Infantil 🧒🛡️

Sistema web interactivo para la gestión de identificación, seguridad y pulseras inteligentes **NFC para Niños**.

## 🚀 Características
- 🏷️ **Escáner y Simulación de Pulseras/Llaveros NFC** (Soporte Web NFC).
- 🆘 **Perfil de Emergencia Infantil**: Acceso rápido a tipo de sangre, alergias, contactos de padres y colegio.
- ➕ **Registro de Nuevos Dispositivos NFC**: Asigna pulseras NFC a niños con un solo toque.
- 📱 **Diseño Ultra Adaptable y Moderno**: Optimizado para smartphones, tablets y escritorio.
- ⚡ **Listo para Vercel**: Configurado para despliegue continuo automático.

## 🛠️ Tecnologías
- HTML5 / Vanilla CSS3 (Glassmorphism, CSS Variables, Responsive Layout)
- JavaScript ES6+ (Web NFC API, LocalStorage, Web Share API)
- Vercel Deployment
